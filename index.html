    Charles Choi: Announcing Burnish
    Org mode is often celebrated for its ability to “write once, export anywhere.” With such power comes added complexity: Exporting a file requires the user to typically go through a multi-step process (e.g. C-c C-e ). If the user is concerned with previewing changes to their file, then another step of viewing the exported output is required. Having to do this repeatedly gets tedious fast. Such is the motivation for Burnish. Burnish is a new Elisp package I’ve made to automate the export and viewing of an Org file. It provides an Emacs minor mode (burnish-mode) that when enabled, does the following upon save of an Org file: Export the Org file to a specified export backend. View the exported output in another Emacs window or by external tool. Most all of the default backends provided by Org mode are supported by Burnish. That said, Burnish is highly configurable, allowing for users to define for themselves the export and view workflow for existing or third party backends. Read the Burnish User Guide to learn more about it. As it is new, feedback is always welcome. If you really find it useful, please show your gratitude by buying me a coffee.
