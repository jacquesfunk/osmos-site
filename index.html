    Charles Choi: Opening Texinfo Web Pages in Emacs Info
    As convenient as accessing online services can be, any disruption in availability without a fallback is painful. Given events of late, many are learning the hard way what it’s like to live without that fallback. GNU Emacs has long supported reading documentation via the Info reader package. Info reader is a “local first” system, where all documentation is stored locally. The source format of the documentation is Texinfo which is exported to different formats, among them Info (used by the Emacs Info reader), HTML, and PDF. Texinfo exported HTML is typically hosted on a website (usually GNU Project), with each Info node mapped to a URL path and indexed by most major search engine services. Discovery of information in Texinfo documentation is frequently done via web search. If the user desires to view that Texinfo web page in the Emacs Info reader, that has to be done manually by corresponding the web page to its Info node. Counterpart is a new utility to automate opening the Info node counterpart of a Texinfo exported web page in Emacs. This utility is designed for Emacs users on macOS who also use the Safari web browser. It requires the installation of a macOS Shortcut which is run from the main menu bar. More detail on using it can be found in the Counterpart User Guide. Once a desired Info node is opened in Emacs, you can then bookmark it for later access, no internet connection required.  ( 1 min )
