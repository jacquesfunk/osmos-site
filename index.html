    Raymond Zeitler: Emacs Windows Management With windmove
    0 Recently I came across the windmove functions1. This discovery caused me to lose interest in bookmarks; now bookmarks are a mere curiosity. The windmove functions allow you to "operate" on a window; the target window is given as a direction relative to point. Operations include: selection, like next-window, but direction overrides window order deletion, like delete-window, but direction indicates the window to delete buffer display (not yet in use by the author) S-, S-, S-, S- for window selection. For example, you can activate the window on the left with windmove-left or S-. Org users already press S- (and S-) on a heading to change TODO status. As well, we press S- (and S-) to increase (decrease) a heading's priority. Luckily, it's easy to specify a different modifier key. I configured my system to make windmove-dir respond to M-s-2 with the following statement: (windmove-default-keybindings '(meta super)) windmove-delete-left. I've defined C-M-s-3 for the windmove-delete-dir functions by adding this to my init file: (windmove-delete-default-keybindings '(control meta super)) other-window (C-x o), sometimes "overshooting" the desired window, or I'd resort to using the mouse to click in it. Now with this intuitive method of selecting windows, I can keep my hands on the keyboard and spend less time figuring out how to get around.     Irreal: Manual Dired Search
    The Art Of Not Asking Why reminds us of a very useful technique for iteratively searching through a series of files for those that contain a given set of terms. The process if simple but very flexible: Open a Dired buffer with the files you want to search. Use %g to do a regular expression search through the files for one of the terms. The files containing the term will be marked. Use t to toggle the marks, resulting in all the files that don’t contain the term being marked. Use k to temporarily hide the marked files, leaving only those that contain the term. Go to step 2 using the next term. A command to search through the contents of the marked files and show the results in another buffer. The nice thing about this method is that it’s interactive: you progressively narrow down the list of target files by eliminating files that don’t contain the terms your looking for. You can, as JTR says, even manually eliminate files that you don’t want to consider as you go along. It’s a good technique and worth remembering.  ( 5 min )
